# Catálogos de estilos

Menús visuales para que el usuario elija rápido ("el subtítulo 3") en vez de describir un estilo desde cero.

Una carpeta por categoría: `subtitulos/`, `titulos/`, `transiciones/`. Se pueden añadir más (rótulos, gráficos de datos…) cuando hagan falta.

## Cómo se añade una entrada

Cada estilo que el usuario aprueba en un proyecto y que puede volver a usarse se guarda como `<categoria>/NN-nombre/`:

- `ficha.md`: descripción en una línea, parámetros (fuente, tamaños, colores, tiempos de animación), en qué proyecto nació.
- `muestra.png` (o un `muestra.mp4` corto si el estilo es de movimiento).
- `codigo.py`: el código que lo genera, parametrizado para colores y fuentes de cualquier marca.

Al preguntar por subtítulos, títulos o transiciones, enviar al usuario las muestras disponibles de esa categoría.
