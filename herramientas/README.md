# Herramientas

Fragmentos de código reutilizables. No es una aplicación: son funciones que Claude lee, importa o copia al trabajar en un proyecto, para no reescribir lo mismo cada vez (llamar a una API, normalizar audio, extraer fotogramas…).

## Reglas

- Solo entra aquí código que ya funcionó en un proyecto real.
- Cada archivo empieza con un comentario que dice qué hace, qué recibe y qué devuelve.
- Las keys se leen de `.env`; nunca se escriben en el código.
- Se ejecuta con el entorno de `.venv/` en la raíz.
